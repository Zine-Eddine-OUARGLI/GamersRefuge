# GamersRefuge

GamersRefuge is an Algerian e-commerce platform specialized in selling gaming products and accessories — from gaming PCs, graphics cards, and monitors to chairs, peripherals, gift cards, and collectible merchandise.

## Tech Stack
- **Frontend:** React + Tailwind CSS
- **Backend:** Node.js (Express.js)
- **Database:** MongoDB
- **Authentication:** JWT / Clerk
- **Payments:** Cash on Delivery (COD) & Online Payment (CIB/Edahabia)
- **Hosting:** Vercel (frontend), Azure / Render (backend)

## Roadmap
1. UI Design & Wireframes (Figma)
2. Build frontend with React + Tailwind
3. Setup backend with Express & MongoDB
4. Authentication (JWT / Clerk)
5. Cart & Checkout with COD + Online Payment
6. Live Support Integration (WhatsApp / Discord)
7. Deployment (Vercel + Azure / Render)
